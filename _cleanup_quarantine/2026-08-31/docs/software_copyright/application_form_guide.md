## 四、软件主要功能（约300字）

本软件是一款面向智能体（Agent）工作流的评测平台。软件提供统一的评测流水线，用于将可调用的智能体接入后，完成测试用例执行、执行轨迹记录、自动评分、对比实验与诊断分析。软件支持评测任务与测试用例的管理，支持以 CSV、JSON 格式批量导入用例；提供内置 ReAct 智能体与外部 HTTP 智能体两种执行方式，通过统一契约接入执行；记录每次执行的完整步骤、Token 消耗、耗时与成本；实现规则指标评分与大模型细化评分相结合的自动评分，并支持人工复核；支持同一用例集下多配置变体的对比实验；提供固定基准用例集、回归试跑与退化检测的持续评测能力；用于对执行轨迹进行根因诊断，输出故障类型与建议；支持对实验进行显著性检验与样本量计算。

## 五、技术特点（约500字）

软件采用前后端分离的分层架构，后端提供评测核心能力与接口服务，前端提供操作界面。

在智能体执行方面，软件通过抽象基类定义统一的执行契约，内置 ReAct 执行器与外部 HTTP 执行器实现同一接口，执行结果统一归一化后进入评测流水线，上层编排无需区分执行器类型。外部智能体接入支持接口探测，并对目标地址做协议、主机名、IP 字面量与 DNS 解析四层校验，用于阻断内网与云元数据地址。

在自动化评测方面，软件的主流水线实现用例加载、并行执行、并行评分、结果聚合与状态判定，各环节可由异步任务队列驱动，完成从执行到评分的完整闭环。

在评分方面，软件采用规则评分与大模型细化评分相结合的混合评分方式，无模型服务时自动降级为规则评分，保证离线可用；评分维度与权重可配置，权重自动归一化到 100 分。

在轨迹分析方面，软件记录执行步骤、Token、耗时与成本，并对轨迹做启发式诊断，归纳执行循环、工具失败、Token 漂移、提示词漂移、超时五类故障，给出置信度与改进建议。

在基准比较方面，软件提供固定基准、回归试跑与退化检测，将本次运行与基线对比判定为提升、持平或退化，支持排行榜与显著性检验，用于量化比较不同配置的表现。
