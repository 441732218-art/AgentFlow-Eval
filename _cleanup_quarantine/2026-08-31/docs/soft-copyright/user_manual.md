# 第1章 概述

本章介绍 AgentFlow-Eval 智能体评测平台的基本信息、核心功能模块、典型适用场景及系统运行所需的软硬件环境。

## 1.1 软件简介

AgentFlow-Eval 是一套面向大语言模型（LLM）智能体的专业评测平台，为研发团队提供从评测任务创建、执行过程监控到结果多维分析的全流程闭环管理。平台内置高性能评测引擎，能够对智能体输出的准确性、语义质量、响应延迟、Token 消耗及 API 调用成本进行综合量化评估。平台同时提供 A/B 对比实验和持续基准测试两大高级功能，帮助团队以数据驱动的方式系统性衡量和持续优化 Agent 表现。

平台采用前后端分离架构：前端为 React + TypeScript 单页应用，后端为 Python FastAPI 服务，数据持久化使用 PostgreSQL 关系数据库。系统支持多租户隔离，不同团队可独立管理各自的评测数据而互不干扰。

## 1.2 核心功能

- **评测任务管理**：创建任务、选择模型、配置 Judge 评分器，支持批量执行和实时进度监控
- **多维结果分析**：自动生成评测报告，包含总分、准确率、质量、延迟、成本等多维度评分
- **轨迹回溯**：完整记录每次评测的执行链路，支持逐步骤查看 Prompt、模型输出和评分细节
- **诊断分析**：自动识别异常用例（超时、低分、格式错误），辅助问题定位
- **对比实验**：支持多个模型/配置的 A/B 离线对比，自动进行统计显著性检验
- **持续评测**：建立标准化 Benchmark 套件，支持 JSON/CSV 导入和排行榜展示
- **插件体系**：可扩展的插件架构，支持自定义评分器和数据处理流程
- **多租户权限**：基于角色的访问控制，支持管理员、评测员、观察者三级权限

## 1.3 适用场景

- **模型选型**：在某业务场景下横向对比多个候选模型（如 GPT-4o、Claude、Gemini），辅助技术选型决策
- **版本回归**：Agent 新版本上线前，运行标准化 Benchmark 验证性能是否出现退化
- **Prompt 工程**：对同一任务配置多组 Prompt 模板，批量评测后对比效果差异，找出最优方案
- **质量监控**：设定周期性评测任务，持续跟踪 Agent 在线上环境的输出质量变化趋势
- **成本优化**：对比不同模型在相同任务下的 Token 消耗和费用，找到性价比最优方案

## 1.4 运行环境

| 环境项 | 最低要求 | 推荐配置 |
|---|---|---|
| 操作系统 | Windows 10/11（64 位） | Windows 11（64 位） |
| Python | 3.10 | 3.11 或 3.12 |
| 数据库 | PostgreSQL 14 | PostgreSQL 16 |
| 浏览器 | Chrome 100+ / Edge 100+ | Chrome 最新版 |
| 内存 | 8 GB | 16 GB |
| 磁盘 | 2 GB 可用空间 | 10 GB SSD |
| 网络 | 可访问模型 API 端点 | 稳定的外网连接 |

# 第2章 安装与部署

本章指导您完成 AgentFlow-Eval 的安装环境准备、依赖安装、数据库配置、服务启动及初始化设置的全过程。请严格按照步骤顺序操作，确保每步完成后再进入下一步。

## 2.1 环境准备

在开始安装之前，请逐一确认以下环境已就绪：

1. 打开命令行窗口（PowerShell 或 CMD），执行 `python --version` 检查 Python 版本。输出须显示 `3.10` 或更高版本号。若未安装，请先到 python.org 下载安装 Python 3.10+，安装时务必勾选"Add Python to PATH"。
2. 执行 `pip --version` 确认 pip 包管理器可用。若提示命令未找到，请重新运行 Python 安装程序并选择修复安装。
3. 确认 PostgreSQL 服务已运行。可在开始菜单搜索"服务"，查看 `postgresql` 服务状态是否为"正在运行"。若未安装，请到 postgresql.org 下载 PostgreSQL 14 或更高版本。
4. 在 PostgreSQL 中创建专用数据库。使用 pgAdmin 或命令行执行以下 SQL：
   ```sql
   CREATE DATABASE agentflow_eval;
   ```
   记下数据库名称、用户名和密码，后续配置需要用到。

## 2.2 安装步骤

1. 将项目源码解压或克隆到目标目录，建议路径为 `D:\AgentFlow-Eval`。确保目录名不含空格和中文字符。
2. 打开命令行窗口，进入项目根目录：
   ```
   cd D:\AgentFlow-Eval
   ```
3. 创建 Python 虚拟环境。虚拟环境用于隔离项目依赖，避免与系统中其他 Python 项目冲突：
   ```
   python -m venv .venv
   ```
4. 激活虚拟环境。激活后命令行前缀会显示 `(.venv)`，表示当前处于虚拟环境中：
   ```
   .venv\Scripts\activate
   ```
5. 安装项目所需的所有 Python 依赖包。此步骤可能需要数分钟，请等待直到命令行提示符再次出现：
   ```
   pip install -r requirements.txt
   ```
   若安装过程中出现红色错误信息，请检查网络连接并重试。常见问题包括：pip 版本过旧（执行 `pip install --upgrade pip`）、缺少 C++ 编译工具（某些包需要编译）。
6. 配置数据库连接。用文本编辑器打开 `backend/app/config.py` 文件，找到数据库配置部分，修改以下字段：
   - `DB_HOST`：PostgreSQL 服务器地址（本地为 `localhost`）
   - `DB_PORT`：端口号（默认 `5432`）
   - `DB_USER`：数据库用户名
   - `DB_PASSWORD`：数据库密码
   - `DB_NAME`：数据库名称（如 `agentflow_eval`）
7. 执行数据库迁移脚本，自动创建系统所需的全部数据表：
   ```
   cd backend
   alembic upgrade head
   ```
   执行成功后控制台输出迁移版本号和"OK"字样。若提示连接失败，请返回第 6 步检查数据库配置。

## 2.3 首次启动

1. 确认虚拟环境处于激活状态（命令行前缀有 `(.venv)`）。若未激活，重新执行 `.venv\Scripts\activate`。
2. 返回项目根目录，执行后端启动命令：
   ```
   python -m backend._start_api
   ```
3. 观察控制台输出。启动过程分以下几个阶段：
   - 加载配置文件
   - 初始化数据库连接池
   - 注册 API 路由
   - 启动 Uvicorn 服务器
4. 当控制台输出 `Uvicorn running on http://127.0.0.1:8000` 时，表示后端服务已启动成功。确认没有红色 ERROR 级别的日志输出。
5. 打开浏览器（推荐 Chrome 或 Edge），在地址栏输入 `http://127.0.0.1:8000` 并回车。若看到带有品牌标识的登录页面，说明系统运行正常。

## 2.4 初始配置

首次启动后，系统需要完成以下配置才能正常使用评测功能：

1. 系统在首次数据库迁移时自动创建默认管理员账户。请使用以下凭据登录：用户名 `admin`，初始密码见项目 `README.md` 文件或联系系统管理员获取。
2. 登录成功后，系统自动跳转至工作台页面。由于尚未配置模型，工作台可能显示空数据，这是正常现象。
3. 点击左侧导航栏的 **设置** 菜单，进入系统设置页面。
4. 在 **模型配置** 区域，点击 **添加模型** 按钮。在弹出的对话框中填写以下信息：
   - **模型名称**：输入模型的标识名，如 `gpt-4o`、`gpt-4o-mini`。名称需与 API 提供商使用的模型代号一致
   - **API 端点**：输入模型提供商的 API 地址。例如 OpenAI 的端点通常为 `https://api.openai.com/v1/chat/completions`
   - **API Key**：输入您的 API 密钥。密钥以 `sk-` 开头，请妥善保管
5. 点击 **测试连接** 按钮。系统会发送一条简短的测试请求验证连通性。若返回绿色成功提示，说明配置正确。若返回红色错误，请检查 API Key 和端点地址。
6. 添加所有需要使用的模型后，在 **通知设置** 标签页中配置评测完成通知（可选）。支持站内通知和邮件通知两种方式。
7. 点击页面底部的 **保存** 按钮，使所有配置生效。

此时系统已完成基本配置，可以开始创建评测任务。建议首先创建一个简单的测试任务验证端到端流程是否畅通。

# 第4章 工作台

本章介绍工作台（Dashboard）的界面布局及关键指标的含义。

## 4.1 工作台概览

登录系统后，默认进入工作台页面。工作台是平台的首页，以可视化图表形式展示当前租户下所有评测活动的汇总数据。

工作台页面包含以下区域：
- **页头**：显示平台名称和当前用户信息
- **统计卡片区**：展示任务总数、完成率、平均分数等关键数字
- **趋势图表区**：以折线图展示近期评测分数的变化趋势
- **最近任务区**：列出最近创建或更新的评测任务

## 4.2 关键指标解读

| 指标 | 说明 |
|---|---|
| **任务总数** | 当前租户下已创建的全部评测任务数量 |
| **完成率** | 已完成任务占全部任务的百分比 |
| **平均分** | 所有已完成任务的加权平均得分（0-100） |
| **活跃模型** | 当前配置且近期有调用记录的模型数量 |
| **Token 消耗** | 指定时间范围内的 Token 消耗总量 |

点击任意统计卡片可跳转至对应的详情页面。趋势图表支持鼠标悬停查看具体数值。

# 第5章 评测任务管理

本章详细介绍评测任务的完整生命周期管理，包括任务列表的浏览与筛选、新任务的逐步骤创建、评测参数的详细配置、任务执行过程中的实时监控以及任务完成后的详情查看。通过本章学习，您将能够独立完成从任务创建到结果产出的全流程操作。

![任务创建](screenshots/task_create.png)

![任务执行](screenshots/task_running.png)

## 5.1 任务列表与筛选

1. 在左侧导航栏点击 **任务**，进入任务列表页面。这是管理所有评测任务的统一入口。
2. 列表以表格形式展示任务摘要信息，每行包含：任务名称、当前状态（等待中/运行中/已完成/失败/已终止）、创建时间、所选模型名称、执行进度百分比。
3. 使用顶部的 **搜索框** 输入任务名称关键词，系统对名称字段进行模糊匹配并实时过滤列表。
4. 使用搜索框右侧的 **状态筛选** 下拉框，可快速筛选特定状态的任务。选择"全部"恢复显示。
5. 点击任意列标题（如"创建时间"），表格按该列升序排列；再次点击切换为降序。
6. 列表底部显示分页控件，可前后翻页或调整每页显示数量（10/20/50/100 条）。

## 5.2 创建评测任务

1. 在左侧导航栏点击 **创建任务**，进入创建页面。页面顶部显示三步骤进度条：基本信息 → 参数配置 → 确认提交。
2. 在 **基本信息** 步骤中填写：
   - **任务名称**：输入易识别的任务名称，建议包含模型和场景信息（如"GPT-4o-mini 客服对话评测 2026Q3"）
   - **描述**（选填）：简要说明评测目的、业务背景等附加信息
   - **评测套件**：从下拉列表选择预设的测试用例集。如需新建套件，点击右侧 **新建套件** 按钮，在弹窗中定义套件名称并逐条添加用例（含输入 Prompt 和可选的期望输出）
3. 确认信息完整后，点击 **下一步** 进入参数配置。

## 5.3 配置评测参数

1. 在 **模型选择** 区域选择待评测的模型。左侧列出系统已配置的全部模型（卡片形式，含名称和启用状态），右侧为已选列表。点击卡片将其加入，支持多选。已选模型卡片高亮并显示勾选标记。
2. 在 **Judge 配置** 区域选择评分策略。系统内置通用评分器覆盖准确性和质量两个维度。如需自定义，选择"自定义评分"后在下方配置各评分维度的名称和权重（权重之和须为 100%）。
3. 展开 **高级设置** 区域，调整以下可选参数：
   - **Temperature**：控制模型输出随机性（0-2，默认 0，即最确定输出）
   - **最大 Token 数**：限制每次模型调用的输出长度上限
   - **超时时间**：单次 API 请求的超时秒数（默认 60）
   - **重试次数**：请求失败后的自动重试次数（默认 0，建议网络不稳定时设为 2）
4. 点击 **创建任务** 提交。系统校验参数后自动将任务加入执行队列，并跳转回任务列表。

## 5.4 执行与进度监控

1. 任务创建后自动进入后台执行队列。在任务列表中找到该任务，状态从"等待中"变为"运行中"。
2. 点击任务名称进入详情页，选择 **进度** 标签页查看实时状态：
   - 顶部进度条显示绿色已完成段和蓝色进行中段，右侧标注百分比
   - 进度条下方显示已用时间和预估值剩余时间
   - 用例执行表格逐行展示每个用例的状态，颜色标识：绿色=成功通过，红色=失败，蓝色=执行中，灰色=等待执行
3. 进度信息每 5 秒自动刷新。任务完成后状态变为"已完成"，进度条显示 100%。
4. 如需提前终止，点击页面顶部的 **终止任务** 按钮并确认。已完成用例的结果保留，未执行用例标记为"已跳过"。

## 5.5 任务详情查看与管理

任务的详情页包含四个标签页，覆盖完整信息：
1. **概览**：显示任务基本信息（名称、描述、创建者、执行耗时）、统计摘要（总用例数 / 通过数 / 失败数）、模型配置快照
2. **用例**：表格逐行列出所有用例，显示用例编号、输入 Prompt 摘要、模型回复摘要及各项得分。点击行展开查看完整的输入输出文本
3. **日志**：按时间轴展示执行日志，支持按级别（INFO / WARNING / ERROR）筛选。出现异常时可在此定位根因
4. **配置**：以只读形式保存创建时的完整参数配置，供后续审计和复现

# 第6章 评测结果与分析

本章介绍如何查看评测报告、解读评分维度、回溯评测轨迹以及使用诊断工具分析问题。

![结果详情](screenshots/result_detail.png)

## 6.1 评测报告列表

1. 在左侧导航栏点击 **报告**，进入报告列表页面。
2. 列表以卡片或表格形式展示所有已完成评测的报告摘要。
3. 每条报告显示：任务名称、执行时间、总体得分、通过用例数。
4. 使用顶部的 **筛选** 下拉框按时间范围或模型筛选报告。
5. 点击任意报告行，进入报告详情页面。

## 6.2 报告详情与分数解读

1. 在报告详情页面顶部，查看 **总分** 和各维度得分（准确性、质量、延迟等）。
2. 向下滚动查看 **分数分布图**，了解各用例得分的分布情况。
3. 在 **用例明细** 表格中，每行包含：用例输入（Prompt）、模型输出（Response）、各维度分数、加权总分。
4. 点击任意用例行，展开查看完整的输入输出内容和 Judge 评语。

> 界面说明：分数分布图默认为柱状图，支持切换到饼图模式。红色区域表示低分用例，绿色表示高分用例。

## 6.3 评测轨迹回溯

1. 在报告详情页面，点击 **查看轨迹** 按钮。
2. 系统跳转至 Trace 页面，展示该次评测的完整执行链路。
3. 左侧为时间轴，按步骤展示：Prompt 构建 → 模型调用 → Judge 评分。
4. 点击任意步骤节点，右侧面板显示该步骤的详细输入输出数据。
5. 使用顶部 **搜索** 框可按关键词过滤轨迹内容。

## 6.4 诊断分析

1. 在左侧导航栏点击 **故障诊断**，进入诊断分析页面。
2. 页面自动汇总近期评测中的异常用例（如超时、低分、格式错误）。
3. 每个异常用例显示：问题类型、发生时间、相关任务、简要描述。
4. 点击用例行，查看详细诊断信息，包括错误堆栈和上下文数据。
5. 使用 **导出诊断报告** 按钮可将诊断结果保存为文件。

# 第7章 对比实验

本章介绍如何使用对比实验（A/B 实验）功能，对不同配置的 Agent 进行离线对比评测。

## 7.1 实验列表与创建

1. 在左侧导航栏点击 **对比实验**，进入实验列表页面。
2. 列表展示所有已创建的实验，每行包含：实验名称、实验状态、创建时间、变体数量。
3. 点击页面右上角的 **新建实验** 按钮。
4. 在创建表单中填写：
   - **实验名称**：为实验命名（如"Prompt A vs B 对比"）
   - **实验描述**：简要描述对比目的（选填）
   - **评测套件**：选择用于评测的测试用例集
5. 添加至少两个 **实验变体**（Variant），每个变体可配置不同的模型、Prompt 模板或参数。
6. 点击 **创建** 按钮提交。系统将自动为每个变体创建对应的评测任务并执行。

> 界面说明：新建实验页面分为基本信息区和变体配置区。变体配置区支持动态添加/删除变体行，每个变体独立配置模型和参数。

## 7.2 实验详情与数据对比

1. 在实验列表页面点击实验名称，进入详情页。
2. 详情页顶部显示实验基本信息及各变体的执行状态。
3. 在 **对比** 标签页中，系统自动生成多维度对比图表：
   - **总分对比**：柱状图展示各变体的加权总分
   - **雷达图**：多维度（准确性、质量、延迟、成本）的雷达对比
   - **逐用例对比表**：每个用例在各变体下的得分明细
4. 平台在对比时自动执行统计检验（z 检验用于比例指标，Welch t 检验用于连续指标），在图表中以置信区间标注显著性差异。
5. 如需导出对比结果，点击 **导出对比报告** 按钮。

> 界面说明：雷达图中每个轴代表一个评测维度，不同颜色的多边形代表不同变体。多边形面积越大表示综合表现越好。置信区间以误差线形式标注在柱状图上。

# 第8章 持续评测

本章介绍如何使用持续评测（Benchmark）功能建立标准化评测基准，跟踪模型性能变化。

## 8.1 创建基准测试套件

1. 在左侧导航栏点击 **持续评测**，进入 Benchmark 管理页面。
2. 页面左侧为 **套件列表**，显示已创建的 Benchmark 套件。
3. 点击 **新建 Benchmark** 按钮，弹出创建对话框。
4. 在对话框中输入 **名称**（如"客服场景基准 V1"）和可选描述。
5. 点击 **确定** 创建套件。新套件将出现在左侧列表中。

> 界面说明：套件列表以紧凑表格形式呈现，每行显示套件名称和已导入用例数量。点击套件行可切换右侧视图。

## 8.2 导入评测用例

1. 在套件列表中点击目标套件，选中它。
2. 点击页面顶部的 **导入用例** 按钮。
3. 在弹出的导入对话框中：选择文件格式（**JSON** 或 **CSV**），点击 **选择文件** 上传本地用例文件。
4. 系统自动解析文件内容，显示预览表格。

# 第9章 数据导出与报告生成

本章介绍如何将评测结果和报告导出为外部文件。

# 第11章 常见问题与故障排除

### Q1：登录时提示"用户名或密码错误"

1. 确认输入的用户名和密码拼写正确，注意大小写。
2. 如连续多次输入错误，账户可能被临时锁定，请联系管理员解锁。
3. 如遗忘密码，请联系管理员在后台重置。

### Q2：评测任务长时间处于"等待中"状态

1. 确认后端服务是否正常运行。在命令行窗口检查是否有错误日志输出。
2. 确认模型 API Key 是否有效且额度充足。在 **设置 > 模型配置** 中点击 **测试连接** 验证。
3. 确认数据库连接正常。检查 `config.py` 中的数据库连接字符串。
4. 如以上均正常，终止当前任务后重新创建。

### Q3：评测完成后报告分数为空

1. 检查评测任务中是否正确配置了 Judge 评分器。在任务详情页的 **配置** 标签页中查看。
2. 确认模型返回的输出格式能被 Judge 解析。在 **Trace** 页面查看模型原始输出。
3. 如果是自定义 Judge，检查评分维度的配置是否正确。

### Q4：导入 Benchmark 用例时提示"格式错误"

1. JSON 文件确认每个用例对象包含 `input` 字段。
2. CSV 文件确认首行为列名（`input,expected`），数据行不包含空行。
3. 检查文件编码是否为 UTF-8。在文本编辑器中另存为 UTF-8 编码后重新导入。

### Q5：对比实验中图表不显示

1. 确认各变体的评测任务均已完成。未完成的变体不会出现在对比图表中。
2. 确认浏览器未阻止 JavaScript 执行。刷新页面后重试。
3. 如问题持续，尝试使用 Chrome 或 Edge 浏览器访问。

# 第3章 登录与账户管理

本章介绍如何登录系统、理解权限角色体系以及管理个人账户设置。

![登录界面](screenshots/login.png)

## 3.1 登录系统

1. 在浏览器地址栏输入平台地址（如 `http://127.0.0.1:8000`），进入登录页面。
2. 在 **用户名** 输入框中输入您的账户名。
3. 在 **密码** 输入框中输入对应的密码。
4. 点击 **登录** 按钮。
5. 系统验证通过后，自动跳转至工作台页面。

> 界面说明：登录页面左侧为品牌标识区，右侧为登录表单。**登录** 按钮下方提供"忘记密码"链接，可联系管理员重置密码。

## 3.2 权限角色说明

平台采用基于角色的访问控制（RBAC），预设以下角色：

| 角色 | 权限范围 |
|---|---|
| **管理员** | 全部功能，包括系统配置、用户管理、所有评测数据 |
| **评测员** | 创建任务、查看报告、执行对比实验、使用基准测试 |
| **观察者** | 仅查看 Dashboard 和公开报告，不可创建或修改数据 |

每个菜单项和操作按钮均受权限控制，无权限的操作将自动隐藏或置灰。

## 3.3 个人账户设置

1. 登录后，点击页面右上角的用户头像或用户名。
2. 在下拉菜单中选择 **个人设置**。
3. 在个人设置页面可修改以下信息：显示名称、登录密码、通知偏好。
4. 修改完成后点击 **保存** 按钮。
