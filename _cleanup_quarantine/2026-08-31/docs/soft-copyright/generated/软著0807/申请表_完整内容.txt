【主要功能和技术特点】（约 200 字）
  AgentFlow-Eval 是一款面向 AI Agent 的自动化评测工作台，支持
  多维度任务驱动评测。核心功能包括：任务全生命周期管理
  （创建、队列、执行、评分、完成）、基于 ReAct 范式的 Agent
  执行器、工具沙箱安全执行环境、规则+LLM 混合多维度评分引擎、
  A/B 对比实验框架、多模态媒体评测（图像/PDF/表格）、插件化
  扩展架构、轻量级多租户隔离与审计日志、WebSocket 实时推送。
  技术栈采用 FastAPI + SQLAlchemy 异步后端、React + Ant Design
  前端，支持 SQLite/PostgreSQL、Redis 缓存、Celery 异步任务队列，
  并内建 AOLS 结构化日志与业务 KPI 可观测性体系。
